# Spring Boot Custom Bean Validation

A Spring Boot grade submission app built for learning purposes —
explores custom Bean Validation with @Constraint, @Target, @Retention,
and ConstraintValidator to implement annotation-based score validation.

## What I Learned

- How to create a **custom annotation** (`@ValidScore`)
- How to use **meta-annotations** (`@Constraint`, `@Target`, `@Retention`)
- How to implement **validation logic** using `ConstraintValidator`
- How `groups()` and `payload()` work in Bean Validation
- How to wire everything together in a **Spring Boot** application

## Tech Stack

- Java
- Spring Boot
- Spring MVC
- Bean Validation (javax.validation)
- Thymeleaf
- Maven
